# WebUI 国际化

Rust Yu WebUI 的所有用户可见文案统一由 `src-tauri/src-frontends/webui/src/i18n` 管理，组件和状态模块中不直接写界面文字。

## 语言文件

- `locales/zh-CN.ts`：简体中文
- `locales/en-US.ts`：英文
- `index.ts`：语言检测、持久化、插值与切换逻辑

每种语言必须使用独立文件，并拥有完全相同的翻译键和插值变量。动态文案使用命名占位符，例如：

```ts
t("app.message_059", { value0: program.name })
```

## 添加新文案

1. 在所有语言文件中添加同名键。
2. 在组件中通过 `t("key")` 使用；不要在 JSX、属性、状态错误或日志格式化代码中直接写界面文字。
3. 含变量的翻译必须在所有语言中保留相同的 `{variable}` 占位符。
4. 运行 `npm test`。其中 `test:i18n` 会检查语言键、占位符、缺失引用、英文文件中的中文以及源码中新出现的中文硬编码。

## 添加新语言

1. 复制一个现有语言文件并完整翻译。
2. 在 `src/i18n/index.ts` 的 `supportedLanguages` 和 `translations` 中注册语言代码。
3. 在设置页的 `languageNames` 中添加对应名称翻译键。
4. 运行测试、构建，并在设置页实际切换验证布局和持久化。

语言偏好保存在 `rust-yu.language`。切换后页面会刷新一次，以便模块级标签、状态格式化器和所有页面同步使用新语言；日期、时间、排序与大小写搜索也会跟随当前语言环境。
