# 开发者模式

Rust Yu 的开发者模式默认关闭。它只为开发、回归测试和真实桌面验收提供入口，不改变普通用户的卸载与清理流程。

## 开启方式

1. 在 Rust Yu 桌面应用中打开“设置”。
2. 开启“开发者模式”。
3. 从侧栏进入“开发者工具”。

该偏好保存在 WebUI 的本机存储中。关闭开发者模式只会隐藏入口，不会卸载已经安装的测试软件。

## 批量安装测试夹具

首批工具支持按顺序静默安装仓库内两个固定夹具：

- `.resources\Xplorer_0.3.1_x64.msi`
- `.resources\inno-legacy-test\output\RustYuLegacyTestSetup.exe`

可以多选，也可以使用“安装全部可用夹具”。开始前必须在确认对话框中再次确认。执行期间会显示当前夹具、总进度和每个安装包的结果；批次完成后会强制刷新已安装软件列表。

## 安全边界

- Tauri 后端只接受固定夹具 ID，并再次将实际文件路径规范化到仓库 `.resources` 目录；前端不能提交任意安装包路径。
- 安装命令要求管理员权限，同一时间只允许一个安装批次。
- MSI 使用 `msiexec /i /qn /norestart`，Inno 使用静默且禁止自动重启的参数。
- 每个安装包最多等待五分钟；超时会停止该安装进程并记录失败，批次内其他结果仍会保留。
- 开发者模式不等同于测试环境隔离。夹具会真实修改 Windows，使用后应通过 Rust Yu 的正常卸载流程清理并检查预期残留。

新增开发者工具时，应继续使用固定命令与结构化参数，补齐 Tauri handler、`AppManifest::commands`、capability 权限、前后端类型、国际化和自动化测试；不得把通用 shell 或任意路径执行能力暴露给 WebUI。
